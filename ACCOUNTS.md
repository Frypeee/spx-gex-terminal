# Акаунти: налаштування (5 хвилин)

Вхід тепер обов'язковий. Користувачі реєструються самі: логін + пароль або Google.
Усі дані (акаунти, налаштування, нотатки, рівні MenthorQ) зберігаються в Upstash, який уже підключений.

## 1. Secrets (Manage app → Settings → Secrets)

```toml
UPSTASH_URL = "..."            # вже є
UPSTASH_TOKEN = "..."          # вже є
APP_SECRET = "довгий-випадковий-рядок"   # шифрує ключі ІІ користувачів; не змінюйте після запуску
ADMIN_USERS = "ваш_логін"      # хто бачить Адмін-панель: логіни або email Google через кому
```

- Без `APP_SECRET` ключ шифрування виводиться з `UPSTASH_TOKEN` (працює, але краще задати свій).
- Якщо `ADMIN_USERS` не задано, адміном стає **перший** зареєстрований акаунт. Зареєструйтеся першим.
- Без Upstash акаунти живуть у пам'яті й зникають при перезапуску (на сторінці входу з'явиться попередження).

## 2. Вхід через Google (необов'язково)

1. [console.cloud.google.com](https://console.cloud.google.com) → APIs & Services → **OAuth consent screen** (External) → заповніть назву й email.
2. Credentials → **Create credentials → OAuth client ID** → Web application.
3. Authorized redirect URI: `https://ВАШ-САЙТ.streamlit.app/oauth2callback`.
4. Додайте в Secrets (значення Client ID і Client secret вводите ви самі):

```toml
[auth]
redirect_uri = "https://ВАШ-САЙТ.streamlit.app/oauth2callback"
cookie_secret = "інший-довгий-випадковий-рядок"
client_id = "....apps.googleusercontent.com"
client_secret = "..."
server_metadata_url = "https://accounts.google.com/.well-known/openid-configuration"
```

Після Reboot app на сторінці входу з'явиться кнопка «Продовжити з Google».
Акаунт Google і акаунт «логін+пароль» з однаковою поштою це **різні** акаунти (так захищено від підміни пошти).

## 3. Що вміє кожен користувач (меню зліва → Кабінет)

- фото, ім'я, email, зміна логіна і пароля, «вийти на всіх пристроях»;
- **Мій ІІ**: власний ключ Anthropic (Claude) або OpenAI; зберігається зашифрованим, перевіряється кнопкою;
- свої налаштування (мова, ТФ, шари графіка, сповіщення, діапазон GEX…) зберігаються в акаунті й підтягуються на будь-якому пристрої;
- свої нотатки й рівні MenthorQ; малюнки на графіку зберігаються окремо для кожного акаунта в браузері;
- видалення акаунта.

## 4. Адмін-панель (меню зліва → Адмін, лише для ADMIN_USERS)

- хто зареєстрований, **хто онлайн зараз**, коли заходив востаннє, скільки входів, IP, чи підключено свій ІІ;
- заблокувати / розблокувати (з причиною; блокування одразу розлогінює), розлогінити скрізь, скинути пароль (тимчасовий показується один раз), видалити;
- журнал: реєстрації, входи, невдалі входи, блокування;
- перемикачі: дозволити нові реєстрації, дозволити спільний ключ ІІ сайту, живі тики LSE.

## 5. Важливо

- **Живі тики LSE**: ключ браузера LSE потрапляє на сторінку лише тим, кому адмін увімкнув «Живі тики» (або всім, якщо ввімкнено для всіх).
- Забули пароль: адмін видає тимчасовий (листів сайт не надсилає).
- Після 8 невдалих входів на один логін вхід блокується на 15 хвилин.
- Паролі зберігаються лише як хеш (scrypt), ключі ІІ шифруються, у базі немає жодного пароля чи ключа у відкритому вигляді.
