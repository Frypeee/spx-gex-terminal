# Хмарний рушій Rithmic (працює без вашого ПК)

Рушій живе всередині сайту на Streamlit Cloud: сам логіниться в Rithmic, приймає кожну угоду ES і NQ (з агресором BUY/SELL),
будує свічки, Ask/Bid-обсяги, дельту та CVD, а графік рухається щосекунди без перезавантаження.
SDK Rithmic до репозиторію не додається (ліцензія Omnesys): протокол реалізовано власним кодом за схемами з пакета RProtocolAPI.

## 1. Secrets (Streamlit Cloud → App → Settings → Secrets)

```toml
RITHMIC_USER = "ваш_логін_rithmic"
RITHMIC_PASSWORD = "ваш_пароль_rithmic"
# необов'язково, але краще вказати, коли система відома:
RITHMIC_SYSTEM = "Rithmic 01"                      # назва «сервера/системи» як у R|Trader або ATAS
RITHMIC_URI = "wss://rprotocol.rithmic.com:443"    # шлюз; за замовчуванням пробуються основні
UPSTASH_URL = "..."                                # той самий Redis, що й для акаунтів: після перезапуску історія не губиться
UPSTASH_TOKEN = "..."
```

Логін і пароль вводьте лише в Secrets, нікому не надсилайте.

## 2. Як перевірити

Відкрийте сайт під адміном → права панель → «Опції» → діагностика. Блок «Rithmic (хмарний рушій)» показує стан, систему,
контракти (ESZ6/NQZ6 визначаються автоматично), кількість угод, історію й помилку.

* «логін відхилено»: у діагностиці є список систем зі шлюзу. Вкажіть свою як `RITHMIC_SYSTEM` і перезапустіть додаток.
  Рушій свідомо пробує вхід рідко (раз на 15–60 хв), щоб не заблокувати акаунт.
* Найчастіша причина відмови: пропфірма не вмикала вам доступ до R | Protocol API. Його дозволяє Rithmic/ваша пропфірма;
  без дозволу логін у R|Trader працює, а в API ні.
* «примусовий вихід»: той самий логін відкрито в іншому місці з обмеженням однієї сесії.

## 3. Що треба знати

* Додаток Streamlit Cloud засинає без відвідувачів (приблизно через 12 годин). Тоді рушій зупиняється; після пробудження він
  підтягне хвилини з Upstash і з History Plant Rithmic (до 30 год), тож CVD сесії відновиться без дірок.
* Щосекундне оновлення свічки йде лише користувачам із дозволом «Живі тики» (адмін має його завжди). Решта бачать ті самі дані з оновленням раз на 15 с.
* Дані CME у реальному часі для сторонніх людей на публічному сайті потребують ліцензії біржі: ваша Rithmic-підписка особиста.
  Щоб показувати їх лише собі та довіреним, додайте в Secrets `RITHMIC_REALTIME_ONLY_ALLOWED = true`: усі без права «Живі тики» тоді бачать Yahoo із затримкою 10 хв.
* Redis використовується економно: запис раз на хвилину (близько 12 тис. команд на добу).
* ПК-воркер `rithmic_worker/` лишається запасним варіантом, якщо хмарний вхід вам не відкриють.
